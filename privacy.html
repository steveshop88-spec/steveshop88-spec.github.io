G-Pilot Privacy Policy

Effective date: 14 October 2026
App: G-Pilot (com.gpilot.app)
Developer / publisher: G-Pilot
Contact: gpilotcoreplus@gmail.com

This policy describes the current G-Pilot Android build. It is intended for a public, no-login page and will be updated if the app adds material data flows such as accounts, cloud sync, advertising, analytics or crash reporting.

1. What this policy covers

This policy explains how G-Pilot handles information when you use the app. G-Pilot is a driver work management and record-keeping tool for recording work income, expenses, goals and related progress.

2. Information stored by G-Pilot

Work income, work expenses, goals, notes, preferences and similar operating records are primarily stored locally on your device in the app's local storage and native local data stores.

G-Pilot does not provide a G-Pilot account or its own cloud database for these records. The current build does not send the ledger to a G-Pilot server. Local entitlement and G-Core state may also be stored to support the features shown in the app.

3. Backup and restore

Backup is user-initiated. G-Pilot can use the Android file picker to export or import a JSON backup file. The current backup flow uses an integrity/checksum mechanism to help detect file corruption. The current G-Core backup seam also supports encrypted backup handling for the relevant G-Core data.

Android automatic backup and device-transfer backup are disabled for the app. G-Pilot does not automatically upload the local ledger to a cloud backup service. An exported file is stored wherever you choose to save or share it, and that destination's privacy practices apply.

4. Google ML Kit language features

The current build uses Google ML Kit Language Identification and on-device Translation for display assistance. A translated display copy does not replace the stored ledger note. ML Kit models may be downloaded through Google's services.

Google's ML Kit Android disclosure describes technical information that may be processed for diagnostics and usage analytics, including device and app information, identifiers or installation information, performance metrics, API configuration, feature input/output size, feature version, event type and error information. Language Identification can involve the identified language, and Translation can involve source and destination language configuration. Google states that this service data is encrypted in transit and is not shared with third parties by ML Kit. G-Pilot does not operate its own server for this feature.

5. Google Play Billing

If you use a Core+ purchase or subscription flow, Google Play handles the Play purchase and subscription communication. G-Pilot receives the product and purchase information needed to determine local eligibility.

Purchase tokens are used transiently for acknowledgement and are not intentionally exposed to the WebView or stored as a user ledger. G-Pilot does not operate its own payment processor or account backend.

6. Permissions and other services

The current build requests network access for SDK, Play services and billing-related communication. It does not request location, contacts, camera, microphone or photo-library permissions.

No advertising SDK, Crashlytics SDK, Firebase Analytics SDK or app-owned analytics/crash endpoint was found in the audited v1.1.0-phase2.1 source and AAB. Third-party services may process technical or purchase-related information under their own policies.

7. Retention and deletion

Local app records remain until you delete them, clear the app's data, uninstall the app, or replace them through the app's data tools. Exported backup files are controlled by you and must be deleted from their chosen storage locations separately.

G-Pilot has no developer cloud ledger to delete in the current build.

8. Children

G-Pilot is intended for adult work and productivity use and is not directed to children.

9. Changes and contact

Material changes to data handling will be reflected in an updated policy. Questions can be sent to gpilotcoreplus@gmail.com.
